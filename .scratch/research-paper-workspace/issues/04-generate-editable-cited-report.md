# 04 — Generate an Editable Cited Literature Report

**What to build:** A researcher can generate an editable Literature Report from
the approved Report Outline and Selected Papers. The report honours the
workspace's Report Language and preserves stable Claim Citations instead of
flattening evidence into an untraceable text string.

**Blocked by:** Wayfinder decisions: Specify the report lifecycle and trust
rules; Choose the single-user application topology; 03 — Generate and Edit a
Report Outline.

**Status:** ready-for-agent

- [ ] Report generation uses the current workspace topic, Report Language,
  approved outline, and only Selected Papers.
- [ ] Each supported report claim can retain one or more validated Claim
  Citations with stable identity across the editor and API response.
- [ ] A researcher can make ordinary text edits in the browser without losing
  report structure or source history.
- [ ] Missing retrieval support and generation failure are displayed as explicit
  report states, not fabricated cited content.
