# Legacy General-RAG Refactor Materials

These documents record PaperRAG's previous direction: a general,
portfolio-oriented knowledge-base RAG system evaluated on a small frozen OpenAI
developer-document corpus. They are preserved because their parser, retrieval,
source-validation, API, CLI, and evaluation work remain useful technical
foundation.

They are not the active product plan. The active direction is the
[research-paper workspace Wayfinder map](../wayfinder/research-paper-workspace.md).
