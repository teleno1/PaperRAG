# File Search With Responses

## Example Flow

The cookbook example combines file preparation and question answering:

- upload files
- create a vector store
- add files to the vector store
- poll until the store is ready
- run a Responses API request with the file search tool

## Why It Matters

- The example demonstrates grounded question answering over prepared documents.
- The example combines Files API, vector stores, and Responses tool usage.
