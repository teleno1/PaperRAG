# 06 — Review and Refresh Citations after Editing

**What to build:** When a researcher substantively changes a cited report
claim, the Claim Citation becomes pending review. The researcher can keep it,
remove it, or refresh it using only the current workspace's Selected Papers.

**Blocked by:** Wayfinder decision: Specify the report lifecycle and trust
rules; 04 — Generate an Editable Cited Literature Report; 05 — Inspect Claim
Evidence and Multiple Sources.

**Status:** ready-for-agent

**Active blockers (supersedes the historical Wayfinder reference above):** 04, 05.

- [ ] A substantive edit never leaves the affected Claim Citation displayed as
  verified.
- [ ] The browser exposes keep, remove, and refresh actions with an explicit
  resulting Citation Review State.
- [ ] Refresh cannot attach a source outside the current workspace's Selected
  Papers and cannot preserve an unknown source identifier.
- [ ] Refresh with no supporting evidence ends in a clear pending or unresolved
  state rather than inventing a citation.
