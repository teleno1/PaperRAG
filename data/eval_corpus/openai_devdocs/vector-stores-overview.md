# Vector Stores Overview

## Purpose

A vector store groups prepared files for retrieval-oriented workflows.

## Population Paths

- Create a vector store before using file search over a collection.
- A store can be populated by adding files directly.
- A store can be populated through file batches.

## Boundary

- Vector store lifecycle is separate from response generation.
- A vector store is a retrieval resource, not a final-answer renderer.
