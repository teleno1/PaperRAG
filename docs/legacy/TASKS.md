# Legacy Task Archive

This file preserves the completed and superseded phase-task index for the
former goal of making PaperRAG a general knowledge-base RAG system. It is **not
the current backlog** and it has no active task.

The active planning source is the local
[research-paper workspace Wayfinder map](../wayfinder/research-paper-workspace.md).
Its frontier tickets govern the next work. See
[README.md](README.md) for the archive policy.

## Archived Goal

The archived refactor aimed to turn the thesis prototype into a reproducible,
general knowledge-base RAG system with generic ingestion, cited answers, and a
small frozen evaluation corpus. Those completed capabilities remain reusable
technical foundation, but their definition of done no longer defines product
success.
