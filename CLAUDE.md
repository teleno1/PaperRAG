# CLAUDE.md

PaperRAG is a single-user research-paper reading and reporting workspace.
Users define a topic, select uploaded or discovered papers, generate an
editable literature report, and trace each cited claim to one or more paper
chunks in the interface.

Read [CONTEXT.md](CONTEXT.md) and the active
[Wayfinder map](docs/wayfinder/research-paper-workspace.md) before working.
