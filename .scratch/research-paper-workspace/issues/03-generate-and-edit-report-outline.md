# 03 — Generate and Edit a Report Outline

**What to build:** A researcher with Selected Papers can generate a default
Report Outline, modify its sections, and approve the version that will guide
the Literature Report. The outline makes the research question, methods and
findings, comparison, limitations or gaps, conclusion, and references editable
rather than forcing a one-shot draft.

**Blocked by:** Wayfinder decision: Specify the report lifecycle and trust
rules; 01 — Create a Research Workspace and Select Uploaded Papers.

**Status:** ready-for-agent

**Active blockers (supersedes the historical Wayfinder reference above):** 01.

- [ ] Outline generation uses only evidence eligible in the current Research
  Workspace.
- [ ] The user can add, remove, rename, and reorder outline sections before
  approval.
- [ ] The workspace retains the approved outline version and exposes its state
  through the chosen browser/API surface.
- [ ] Empty or not-yet-ready Selected Paper sets produce an understandable
  action instead of an apparently valid outline.
